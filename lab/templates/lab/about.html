05 ABOUT THE PROJECT

Make the logic
visible.

SortLab is an interactive learning project for understanding how sorting algorithms make decisions.

THE PURPOSE

From final output
to visible process.

Sorting is often taught through pseudocode and final arrays. SortLab exposes the operations between those two points: comparisons, swaps, writes, partitions and sorted regions.

THE TECHNOLOGY
  • Python Django application and URL routing
  • HTML / CSS Responsive interface and visual system
  • JavaScript Sorting traces, playback and comparison
  • SQLite Default Django database configuration
ARCHITECTURE NOTE

Django serves the pages and static assets. Sorting operations are generated and animated in the browser using JavaScript. The current project does not store user-entered arrays or results in the database.
